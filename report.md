# Цель работы

Изучить идеологию и применение средств контроля версий, освоить практические навыки работы с инструментарием Git и сопутствующими сервисами (GitHub, GitHub CLI).

# Задание

1. Установка и базовая настройка Git (имя пользователя, email, обработка окончаний строк).
2. Создание и настройка аутентификации по ключам SSH.
3. Настройка авторизации и работы с репозиториями через утилиту `gh`.

# Теоретическое введение

Системы контроля версий (VCS) фиксируют изменения в файлах проекта, позволяя возвращаться к предыдущим состояниям, отслеживать историю и вести совместную разработку. Git — распределенная система контроля версий, где каждый разработчик имеет локальную копию всей истории репозитория, что обеспечивает автономность и высокую скорость работы.
