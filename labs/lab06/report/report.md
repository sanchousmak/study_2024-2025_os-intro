# Цель работы
Ознакомление с инструментами поиска файлов и фильтрации текстовых данных, изучение команд CLI для эффективного анализа логов и конфигурационных файлов в Linux.

# Задание
1. Осуществить поиск файлов по заданным критериям с помощью утилиты `find`.
2. Выполнить фильтрацию строк в текстовых файлах с использованием регулярных выражений и утилиты `grep`.
3. Ознакомиться с базовыми конвейерами (pipes) обработки данных.

# Теоретическое введение
В операционных системах семейства Unix поиск и фильтрация текстовой информации являются ключевыми операциями автоматизации. Утилита `find` производит рекурсивный поиск в иерархии каталогов по имени, типу, размеру и правам доступа. Утилита `grep` осуществляет поиск совпадений по шаблонам (включая регулярные выражения) внутри содержимого файлов, передавая отфильтрованный результат в стандартный вывод.
